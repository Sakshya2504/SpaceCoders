# 5-minute judging demo

1. Login with `charge@patienttriage.demo / demo123`.
2. Show command-centre metrics and the explicit safety rules.
3. Open Waiting Queue and choose a high-acuity patient.
4. Show ESI, confidence, action tier, evidence and feature contributions.
5. Record a clinician override with a reason, then open Audit Trail.
6. Create a zero-history patient and show reduced confidence; create a pediatric patient and explain age-band thresholds.
7. Toggle **Surge mode ON**, then press **Reassess now**; explain the 5→1 minute cadence.
8. Explain fail-open: inference failure returns control to manual ESI instead of blocking care.
