# Final model artifact

The final model supplied for application integration is:

```text
triage_ensemble_model.pkl
```

It contains five LightGBM base models, five XGBoost base models, fold-specific categorical mappings, and a LogisticRegression stacking model.

## Local installation

The binary artifact is intentionally not stored in this source repository. Copy the supplied file into this directory:

```text
ml/artifacts/triage_ensemble_model.pkl
```

On Windows PowerShell, from the repository root:

```powershell
Copy-Item .\triage_ensemble_model.pkl .\ml\artifacts\triage_ensemble_model.pkl
```

The expected SHA-256 checksum of the supplied artifact is:

```text
8a22c60268cb26fab39935cbd087c74568658db32da26f99f662559288d06ccc
```

The model contains the exact feature order generated by the supplied final notebook. The runtime reads that order directly from the artifact instead of maintaining a second hard-coded feature list.
